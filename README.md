# volunteer-platform
A software application to help community organizations organize tasks, register volunteers, record work data, and send automatic messages.

## Run the prototype

Requires Java 17 or later and Maven.

```
mvn spring-boot:run   # open http://localhost:8080
mvn test              # run all unit and API tests
```

Demo accounts (password `password`): `volunteer@voluntier.test`, `coordinator@voluntier.test`, `admin@voluntier.test`.
